Who the loop serves

P1Reporter: developer, QA or designerI pointed at the problem and said what is wrong. I did not write a ticket by hand.
P2Triage owner: PM or leadI see all feedback in groups, and I turn a group into one good ticket.
P3Assignee: developer with the ticketThe ticket tells me which component, which file and where on the page.

The map

Covered means designed, built and covered by an e2e test. Built, no test has code but no e2e test. Built, no design is tested code that has no Penpot board. Partial and Missing describe the code.

What to fix first

Ranked by impact on the core promise (“select, comment, create, and the ticket has everything”) against effort. Effort is a first guess: S is under a day, M a few days, L a week or more.
