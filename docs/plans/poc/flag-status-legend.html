Lifecycle: No Task → To Do → In Progress → Code Review → Test → Test Passed → UAT → In Preprod → In Production → Done

Design Decisions

Position: Flagged appears at the top, before workflow statuses, with an "OVERRIDES" separator to visually communicate the business rule.

Visual treatment: The flagged row has a subtle red background tint and a 3px left border to distinguish it from workflow statuses.

Color distinction: Flagged red (#dc2626, red-600) vs Won't Do red (#ef4444, red-500). Different shades — and different visual channels (border vs badge fill) — prevent confusion.

Business Rule: Flagged is not a workflow status — it's a cross-cutting concern. A ticket can be "In Progress" AND "Flagged" simultaneously. That's why it sits above the workflow list with an explicit "OVERRIDES" label.
