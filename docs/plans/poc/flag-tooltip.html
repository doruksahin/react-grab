Tooltip Content

Shows on hover over the flag icon + relative time:

1. Header: Flag icon + "Flagged / Blocked" label in red
2. Who: Avatar (24px circle) + display name + "Flagged by" label
3. When: Exact date down to the minute (e.g. "Apr 14, 2026 at 17:32") + "Flagged at" label

Data source: JIRA changelog entry for field: "Flagged" → author.displayName, author.avatarUrls['48x48'], created timestamp.

Implementation: Existing Kobalte Tooltip component with shadow DOM portal mounting. Wrap the flag icon + relative time in TooltipTrigger.
