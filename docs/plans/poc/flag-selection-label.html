Business Rule: Flagged Overrides Status

RULE (ADR-0009): When a JIRA ticket is flagged, the red border (#dc2626) is shown regardless of the current workflow status. The status badge retains its original color — so you can see "In Progress" (blue badge) + "Blocked" (red border) simultaneously. The border is the flag; the badge is the status.
